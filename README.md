# AveDex 🐦

A AveDex é um catálogo interativo de aves desenvolvido em Python.

## Funcionalidades atuais

- Exibição de mensagem de boas-vindas;
- Listagem de aves cadastradas;
- Busca de aves por código;
- Exibição dos detalhes das aves;
- Menu interativo.

## Conteúdos praticados

- Variáveis;
- Condicionais;
- Estruturas de repetição;
- Funções;
- Listas;
- Dicionários;
- Organização de código.

## Boas práticas aplicadas

- Separação de responsabilidades em funções;
- Código organizado e reutilizável;
- Uso de nomes claros para variáveis e funções;
- Testes manuais antes das alterações.

## Evolução do projeto

Nesta versão, o catálogo foi ampliado com novas aves.
As informações foram organizadas em uma lista de dicionários,
e as funcionalidades foram separadas em funções para facilitar
a manutenção e evolução do sistema.
